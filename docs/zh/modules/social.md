# 社交通讯

## 概览

社交通讯模块包含论坛、问答等社交功能。

## 子模块

### 💬 论坛

| 特性 | 说明 |
|------|------|
| **功能** | 帖子发布、评论、点赞 |
| **同步范围** | 全平台可见 |

### ❓ 问答

| 特性 | 说明 |
|------|------|
| **功能** | 提问、回答、投票、标记已解决 |

## API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/social/forum` | 获取帖子列表 |
| POST | `/api/v1/social/forum` | 创建帖子 |
| GET | `/api/v1/social/forum/:id` | 获取帖子详情 |
| POST | `/api/v1/social/forum/:id/comments` | 发表评论 |
| GET | `/api/v1/social/forum/:id/comments` | 获取评论列表 |
