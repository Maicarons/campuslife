# 校园生活

## 概览

校园生活模块整合了食堂、外卖、失物招领、活动、地图、校车和公告等校园日常信息服务。

## 子模块

### 🍽️ 食堂菜单

| 特性 | 说明 |
|------|------|
| **功能** | 各食堂菜品展示、营养分析、收藏 |
| **同步范围** | 学校（全校共享） |
| **AI** | 营养搭配建议 |
| **OCR** | ✅ 拍照识别菜单 |
| **上传积分** | +5 |

### 🛵 外卖聚合

| 特性 | 说明 |
|------|------|
| **功能** | 校内外卖平台汇总、优惠信息 |
| **同步范围** | 学校 |
| **AI** | 个性化点餐推荐 |
| **上传积分** | +3 |

### 🔍 失物招领

| 特性 | 说明 |
|------|------|
| **功能** | 发布/搜索失物招领信息 |
| **同步范围** | 学校 |
| **AI** | 图像识别辅助分类 |
| **OCR** | ✅ 图片识别 |
| **上传积分** | +5 |

### 🎭 校园活动

| 特性 | 说明 |
|------|------|
| **功能** | 活动日历、报名、提醒 |
| **同步范围** | 学校 / 学院 |
| **AI** | 个性化活动推荐 |
| **上传积分** | +8 |

### 📢 公告通知

| 特性 | 说明 |
|------|------|
| **同步范围** | 任意层级 |
| **优先级** | 普通 / 重要 / 紧急 |

## API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/campus/dining` | 餐饮点列表 |
| GET | `/api/v1/campus/dining/:id` | 餐饮点详情 |
| POST | `/api/v1/campus/dining` | 上传餐饮点 |
| POST | `/api/v1/campus/dining/:id/reviews` | 发表评价 |
| GET | `/api/v1/campus/lost-found` | 失物招领列表 |
| POST | `/api/v1/campus/lost-found` | 发布失物招领 |
| GET | `/api/v1/campus/events` | 活动列表 |
| GET | `/api/v1/campus/announcements` | 公告列表 |
